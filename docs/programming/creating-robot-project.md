# Creating a Robot Project

- open github and find the 4256-Template-Robot repository
- select the "Use this template" button
- choose create a new repository

- open FRC VS code
- use the command palette by selecting cmd + shift + p
- select git clone
- enter the URL of the new repository

- the repository comes with pre-configured vendor libraries
- AdvantageKit
- ThriftyLib
- PhotonVision
- 4256-2026-Lib

- the robot file is pre-configured setup for subsystems and the state scheduler
